## Magic UI Grid Pattern (21st.dev community component)

`frontend/src/components/ui/grid-pattern.tsx` adapts the MIT-licensed [Grid Pattern component published on 21st.dev](https://docs.21st.dev/@dillionverma/components/grid-pattern), from [Magic UI's source registry](https://magicui.design/r/grid-pattern.json). Adaptations use local design tokens, omit unused configuration and hide the decorative SVG from assistive technology. The grid is static, avoiding continuous background animation in an investigation workspace.
